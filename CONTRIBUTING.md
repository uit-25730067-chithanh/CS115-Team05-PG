# [CS115] Team 05 - Contribution & Confidentiality Policy

Welcome to Team 05! This document outlines how to contribute and what files must **not** be shared to ensure project security and personal configuration safety.

---

## 🔒 Confidentiality Rules (IMPORTANT)

To avoid leaking personal AI configurations and project internal plans, the following files/directories are **HEAVILY RESTRICTED** and must **NEVER** be pushed to GitHub:

- `CLAUDE.md` (AI instructions)
- `AGENTS.md` (Sub-agent roles)
- `docs/` (Internal documentation/notes)
- `plans/` (Implementation roadmaps)

**Action**: They are already listed in `.gitignore`. **DO NOT** use `git add -f` to force them into the repository.

---

## 🏗 Coding Guidelines

- **No AI-Copying**: Use AI tools (ChatGPT, Claude) only for brainstorming and explaining concepts. You **must understand** the code you write.
- **Language**: Source code comments, commit messages, and API docs should be in **English**.
- **Response Time**: Respect the **12-24 hours** response rule established in our kick-off meeting.

---

## 🚀 Git Workflow

1. Sync your local `main` with `origin/main` before starting.
2. If working on a new experimental feature, create a separate branch.
3. Check with the **Math Lead (Anh Sơn)** or **Code Lead (Anh Ý)** before merging code into `main`.
